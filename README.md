# StayFair demo

StayFair is an early **prototype** of a vacation-rental marketplace with service fees 40% lower than Airbnb's for both guests and hosts.

**Live demo:** https://whitetailridgemobile.github.io/stayfair-demo/

- Everything here is **sample data**: the listings, hosts, and bookings are fictional.
- **No real payments.** Checkout is a pretend demo, and no card is ever charged.
- There is no server. Bookings and new listings are saved only in your own browser, and you can clear them with **Reset demo** at the bottom of the page.
- Airbnb fee comparisons use Airbnb's published service fees (https://www.airbnb.com/help/article/1857, checked 2026-10-04). Photos are from Unsplash.

This repository contains only the built static site.
